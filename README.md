Sums up Tuesday 17 November 2026's world news in one image. `main.py` (Python 3.13, standard library only) draws a 1024×1024 newspaper front page at run time — masthead naming the day, plus six story panels: the Kerch Bridge strike, the Russian military plane crash, Depardieu admitting the charge, the Western call for Gaza aid access, the Quad summit in Manila, and the US losing measles-free status. Text is drawn with a built-in 5×7 bitmap font, so the output is deterministic: two runs produce byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
